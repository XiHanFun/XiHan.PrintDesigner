打印客户端 SDK ​

@xihan-print/runtime/client 连接本地打印客户端：静默打印、写原始指令、导出 PDF、查打印机。这个子入口单独打包，不用客户端的页面不会加载它。

创建连接 ​

createPrintClient() ​

ts
declare function createPrintClient(options?: PrintClientOptions): PrintClient

创建本地打印客户端的连接；不会立即连接，第一次调用时才连。

PrintClientOptions ​

createPrintClient 的选项。

属性类型说明
ports?readonly number[]按顺序探测的端口，缺省 17620–17623。
timeoutMs?number请求等响应的期限，缺省 10 秒。
connectTimeoutMs?number每个端口建连的期限，缺省 3 秒。
consentTimeoutMs?number客户端弹出授权窗口后等用户决定的期限，缺省 75 秒。
reconnect?boolean断线后是否自动重连，缺省 true。
WebSocket?WebSocketConstructorWebSocket 构造函数，缺省为全局 WebSocket。
permissions?PermissionsLike | null查本机网络权限的入口，缺省为 navigator.permissions；为 null 时不查。
secureContext?boolean页面是否是安全上下文，缺省为全局 isSecureContext。
origin?string页面的来源，缺省为全局 location.origin；页面本身在本机回环地址上时，连不上不按本机网络权限判定。
fetch?typeof fetch打包文档时取资源用的 fetch，缺省为全局 fetch。

PrintClient ​

本地打印客户端的连接。

属性类型说明
statePrintClientState连接状态。
welcomeClientWelcome | undefined最近一次握手的结果；还没连上过时为 undefined。
方法说明
connect(): Promise<ClientWelcome>连接并握手；已连着时直接返回握手结果。连不上抛 PrintClientError，码为 CLIENT_UNAVAILABLE、LOCAL_NETWORK_DENIED、PROTOCOL_UNSUPPORTED、CONSENT_DENIED、CONSENT_TIMEOUT 等。
close(): void断开连接，不再重连；未结束的任务以 CONNECTION_LOST 拒绝，客户端里的任务照常执行完。
printers(): Promise<PrinterInfo[]>列出打印机，不含能力明细。
printer(name: string): Promise<PrinterInfo>查一台打印机，含能力明细。
printDocument(schema: PrintDocument, data: unknown, options?: PrintClientDocumentOptions): PrintClientJob按数据排出模板并交给客户端打印。
printSheets(result: PaginationResult, options?: PrintClientDocumentOptions): PrintClientJob把排好的输出页交给客户端打印。
printRaw(printer: string, data: Uint8Array | ArrayBuffer | string, options?: PrintRawOptions): PrintClientJob把原始指令原样写给打印机；字符串按 UTF-8 编码，要别的编码时先转成字节。
exportPdf(schema: PrintDocument, data: unknown, options?: PrintClientDocumentOptions): Promise<Blob>按数据排出模板并导出为 PDF。
exportSheetsPdf(result: PaginationResult, options?: PrintClientDocumentOptions): Promise<Blob>把排好的输出页导出为 PDF。
job(jobId: string): Promise<JobStatus>查任务状态。
on<K extends keyof PrintClientEventMap>(type: K, listener: (detail: PrintClientEventMap[K]) => void): () => void订阅事件，返回退订函数。

PrintClientJob ​

一个交给客户端的任务。

属性类型说明
idstring任务标识，由 SDK 生成。
statusJobStatus | undefined最近一次的状态；还没交给客户端时为 undefined。
donePromise<JobStatus>completed 时兑现；failed 时以客户端给出的错误码拒绝，cancelled 时以 JOB_CANCELLED 拒绝，发送前出错时以对应错误拒绝。
方法说明
onStatus(listener: (status: JobStatus) => void): () => void订阅状态变化，返回退订函数。
cancel(): Promise<boolean>取消任务：排队中的立即取消并返回 true；执行中的尽力取消并返回 false，结果以状态为准。

PrintClientEventMap ​

客户端派发的事件。

用 client.on(type, listener) 订阅。连接状态 PrintClientState 取 idle、connecting、open、reconnecting、closed。

属性类型说明
statePrintClientState连接状态变化。
consentpending{ readonly origin: string }来源还没授权，客户端已弹出授权窗口。

退回浏览器打印 ​

printWithFallback() ​

ts
declare function printWithFallback(client: PrintClient, schema: PrintDocument, data: unknown, options?: PrintWithFallbackOptions): Promise<PrintWithFallbackOutcome>

先交给本地打印客户端打印，等到交给打印池；只在连不上客户端（CLIENT_UNAVAILABLE、PROTOCOL_UNSUPPORTED）时退回浏览器的打印对话框。打印机报错、拒绝授权等其它错误照常抛出，免得用户以为已经静默打出来了。

PrintWithFallbackOptions ​

printWithFallback 的选项：客户端打印选项、分页注入项，退回浏览器打印时另用 title。

继承 PrintClientDocumentOptions、Pick<PrintOptions, 'title'>。

PrintWithFallbackOutcome ​

printWithFallback 的结果：走了哪条路，与送去打印的页数。

属性类型说明
via'client' | 'browser'
sheetsnumber

shouldFallBack() ​

ts
declare function shouldFallBack(error: unknown): boolean

这个错误是否表示连不上客户端、应该退回浏览器打印；打印机报错、拒绝授权等一律不退回。

错误码 ​

出错时抛出或以 PrintClientError 拒绝，code 为下表之一，details 带补充信息。「SDK」一栏的码在浏览器里产生，其余由客户端给出。

错误码出自说明退回浏览器打印
CLIENT_UNAVAILABLESDK所有端口都连不上（客户端没装或没运行），details 带端口 ports 与浏览器报的「本机应用」权限状态 permission（查不到时不带）是
LOCAL_NETWORK_DENIEDSDK连接在浏览器里就被拦下：页面不在本机回环地址上、所有端口都在建连期限内失败，且「本机应用」权限被拒或页面不是安全上下文否
CONNECTION_LOSTSDK等结果时断线，或断线后没能在期限内重连上否
TOO_MANY_CONNECTIONSSDK同一来源的连接数超过客户端上限否
TIMEOUTSDK请求没有在期限内得到响应否
JOB_CANCELLEDSDK任务被取消否
BAD_REQUEST客户端消息格式或字段不合法否
CONSENT_PENDING客户端授权窗口还开着时又发了业务请求否
CONSENT_DENIED客户端用户拒绝，或来源在拒绝名单否
CONSENT_TIMEOUT客户端授权窗口在期限内没人处理否
SESSION_EXPIRED客户端重连令牌过期或不属于这个来源，已当作新会话否
PROTOCOL_UNSUPPORTED客户端协议主版本不匹配是
NO_PRINTERS客户端本机没有任何打印机否
PRINTER_NOT_FOUND客户端指定的打印机不存在否
PRINTER_OFFLINE客户端打印机脱机、暂停或出错否
PAPER_UNSUPPORTED客户端打印机没有任务需要的纸张，且驱动不接受自定义尺寸否
DOCUMENT_TOO_LARGE客户端超过消息上限或资源总量上限否
RESOURCE_BLOCKED客户端文档里引用了随任务带来的资源之外的地址否
RENDER_FAILED客户端渲染引擎载入或等待就绪失败否
RENDER_TIMEOUT客户端渲染超时否
SPOOL_FAILED客户端交给打印池失败否
PDF_FAILED客户端导出 PDF 失败否
JOB_DUPLICATE客户端任务标识重复否
JOB_NOT_FOUND客户端查无此任务否
QUEUE_FULL客户端同一会话排队的任务超过上限否
CAPABILITY_UNSUPPORTED客户端请求了客户端没有的能力否
INTERNAL客户端未预期的异常否

提醒码 ​

HTML 通道的任务照常完成、但有宿主应当知道的情况时，JobStatus 的 warnings 里带若干条提醒（ClientWarningPayload），code 为下表之一，details 带补充信息。

提醒码说明
PAPER_UNCHECKED驱动没有报纸张能力，或读不出驱动会留下哪种纸，没有核对纸张就照常下发了
PAPER_FITTED按 fitToNearestPaper 把某组改用了最接近的纸张：比纸大的内容按 scale 等比缩小，比纸小的原大居中

打印选项与结果 ​

ClientPrintOptions ​

交给客户端的打印选项。纸张不在选项里：每组输出页按模板里的纸张尺寸下发；原始指令的纸张由指令自己决定。

属性类型说明
printer?string打印机名称，缺省为默认打印机。
copies?number份数，1–999。
collate?boolean多份时逐份打印，缺省 true。
duplex?'simplex' | 'long-edge' | 'short-edge'
color?'color' | 'grayscale'
pageRanges?string页码范围，如 1-3,5。
dialog?boolean弹系统打印对话框，缺省静默打印。
timeoutMs?number交给打印池的期限，毫秒。
fitToNearestPaper?boolean打印机没有某组的纸张、驱动也不接受这个尺寸时，改用最接近的纸张，比纸大的内容等比缩小到放得下，比纸小的原大居中；缺省 false，这时整个任务以 PAPER_UNSUPPORTED 失败。

PrintClientDocumentOptions ​

打印与导出的选项：客户端打印选项、分页注入项与打包文档的选项。

继承 ClientPrintOptions、PrintRenderOptions、Pick<ClientDocumentOptions, 'document'>。

PrintRawOptions ​

写原始指令的选项。

属性类型说明
docName?string打印池里显示的文档名，缺省为任务标识。

JobStatus ​

任务的当前状态。

任务状态 JobState 取 queued、started、completed、failed、cancelled。

属性类型说明
jobIdstring
stateJobState
position?number排队时同一台打印机前面还有几个任务。
sheets?numberHTML 通道交给打印池的页数。
bytes?number原始通道写出的字节数，或导出的 PDF 大小。
error?ClientErrorPayload
warnings?readonly ClientWarningPayload[]HTML 通道完成时的提醒，如没能核对纸张、按 fitToNearestPaper 换了纸；没有时缺省。

交给客户端的文档 ​

buildClientDocument() ​

ts
declare function buildClientDocument(result: PaginationResult, options?: ClientDocumentOptions): Promise<ClientDocument>

把分页结果打包成交给客户端的文档：输出页渲染进一份独立的 HTML（只在预览中显示的元素不画），图片、背景图与模板用到的字体取来随任务带去，地址改写成客户端里的资源地址。

ClientDocumentOptions ​

打包文档的选项。

属性类型说明
document?Document发起打印的文档：从它的样式表里找模板用到的字体，相对地址也按它解析；缺省为全局 document。
fetch?typeof fetch取资源用的 fetch，缺省为全局 fetch。
extensions?readonly PrintRuntimeExtension[]扩展：扩展元素按它们给的渲染画出，与分页用同一份。
trace?PrintTrace各环节的回调：报生成 DOM、取资源与合成文档三个环节的起止，见 PrintTrace。

ClientDocument ​

交给客户端的文档：自包含的输出页、资源与按出现顺序的纸张分组。

属性类型说明
htmlstring
resourcesreadonly ClientResource[]
sheetsreadonly ClientSheetGroup[]

ClientResource ​

随任务带去的一份资源，data 为 base64。

属性类型说明
idstring
typestring
datastring

ClientSheetGroup ​

连续的若干张同尺寸输出页。

属性类型说明
widthMmnumber
heightMmnumber
countnumber

常量 ​

名称值说明
DEFAULT_PORTS[17620, 17621, 17622, 17623]客户端监听的端口，按顺序探测。
SUB_PROTOCOL'xihan-print.v1'带主版本的子协议。
PROTOCOL_VERSION1协议主版本。
PROTOCOL_MINOR0协议次版本：只加不减。

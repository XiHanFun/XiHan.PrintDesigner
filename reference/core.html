模型层 core ​

@xihan-print/core 是纯 TypeScript 的模型层：模板类型、校验、编辑操作、元素登记表与分页算法，不依赖 DOM，浏览器、Node.js 与其它 JavaScript 运行环境里都能用。模板类型的字段见模板类型，元素属性见元素。下表按源码模块列出全部导出。

operations/table-plans ​

名称种类说明
MIN_TABLE_COLUMN_WIDTH常量调整列宽时每列的最小宽度，单位 mm。
planInsertFooterRow函数在第 index 个表尾行之前插入一行（index 等于行数时追加）。
planInsertTableColumn函数在第 index 列之前插入一列（index 等于列数时追加在末尾）；跨过插入位置的表尾单元格多跨一列，其余表尾行在新列处留空。
planMergeFooterCells函数合并表尾行里 columnIds 覆盖的列范围：与范围相交的单元格（含留空的列）合成一个，合并后的范围扩到它们的并集；保留最左边那个单元格的内容，最左边是留空的列时新建空白单元格。
planMoveTableColumn函数把一列移到第 index 位（按移动后的顺序数）。
planRemoveFooterRow函数删除一个表尾行。
planRemoveTableColumn函数删除一列：只占这一列的表尾单元格删除，跨过它的缩短一列，从它起跨的改由下一列起跨。
planResizeTableColumn函数把一列调到 width 宽，不小于 MIN_TABLE_COLUMN_WIDTH。
planSplitFooterCell函数把表尾行里从 columnId 起跨的单元格拆成只占一列，空出来的列留空。
TableColumnFit类型列宽怎样跟着变：keep 保持表格宽度、各列按比例缩放；resize 改变表格宽度、其余列不动。
TablePlanRefusal类型计划不能执行的原因：只剩一列、移动会拆开跨列的表尾单元格、所选范围只有一个单元格、单元格本来就不跨列。
TablePlanResult类型计划结果：成功时给出 updateElement 的属性修改。

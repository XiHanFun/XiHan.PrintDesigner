设计器 ​

@xihan-print/designer 的公开接口。样式在 @xihan-print/designer/style.css，还要同时引入 @xihan-ui/designer-shell/style.css 与 @xihan-print/runtime/style.css。

<xh-print-designer> ​

注册 <xh-print-designer>；重复调用不报错。

属性 ​

属性attribute类型说明
data—unknown预览分页用的数据。
sampleData—unknown示例数据：给出时画布按它显示实际值，不给时字段显示 {path} 占位。
fields—readonly DataField[] | undefined可绑定的字段树：物料面板「字段」组与属性面板的字段选择器读它；导入字段时设计器换掉它并派发 fields-change。
fieldsReadonlyfields-readonlyboolean字段由宿主管着、不许在设计器里导入：物料面板头没有导入字段钮，import-fields 命令不可用。attribute 为 fields-readonly。
expressionEngine—ExpressionEngine | undefined受限表达式引擎；缺省为 @xihan-ui/expression 的 createExpressionEngine()。
formatter—ValueFormatter | undefined值格式化器；缺省为 @xihan-ui/expression 的 formatValue。
measurer—TextMeasurer | undefined文字度量器；缺省用所在文档的 Canvas 度量器。
printClient—PrintClient | undefined本地打印客户端：给了时打印先交给它静默打印，连不上客户端才退回浏览器打印；设置里的打印方式选了浏览器时直接用浏览器打印。给了它，设置对话框才有打印方式一项与「本地客户端」一页。
clientDownloadUrlclient-download-urlstring | undefined设置对话框「本地客户端」一页里「下载客户端」链接的地址，缺省 PRINT_CLIENT_DOWNLOAD_URL；attribute 为 client-download-url。
localelocalestring | undefined交给格式化器的区域，只决定小数点与千分位符号；同名 attribute。
timeZonetime-zonestring | undefined交给格式化器的时区：UTC、±HH:mm 或 IANA 名称；attribute 为 time-zone。
translations—Partial<PrintDesignerTranslations> | undefined元素自己的文案，压在全局配置之上。
readonlyreadonlyboolean只读：可以选择、浏览与预览，不能修改。attribute 三态：不写或移除为不只读，写 "false" 为不只读，其余写法为只读。
modemodePrintDesignerMode设计态或预览态，缺省 design；同名 attribute。
defaultLayout—DesignerLayout | undefined宿主的缺省面板布局：用户没存过布局（settings 里没有 layout.panels）时用它，「恢复默认布局」也回到它；写了的字段整项覆盖内置缺省。面板 id 见 PRINT_DESIGNER_PANELS。
commandLayout—DesignerCommandLayout | undefined工具栏与右键菜单的排列：位置（toolbar、menu:blank、menu:element、menu:table）→ 若干组命令 id，内置与扩展的命令可以混排。写了某个位置就只显示列出的命令；写了没登记的命令 id 时抛 TypeError。
settings—DesignerSettings | undefined设置的值：扁平的键值，键是「分区 id.条目 id」，如 general.theme、print.showGrid；没写的键取条目的缺省值。赋值即生效；用户在设置对话框里或用工具栏上的网格、吸附开关改了以后，设计器换成新的一份并派发 settings-change。
settingsPolicy—DesignerSettingsPolicy | undefined宿主对设置条目的管控：键是条目键或分区 id，hidden 不显示，locked 只读、说明换成「由所在系统管理」。
settingsStorageKeysettings-storage-keystring | undefined设置存在根所在窗口 localStorage 的哪个键下：给了，连上文档时若没赋 settings 就从这里读，用户改了设置就写回去，标了 secret 的条目不存；读写失败派发 settings-storage-error。不给就不读写。同名 attribute settings-storage-key。
draftKeydraft-keystring | undefined自动保存草稿的键：区分同一页、同一种设计器里的不同模板（宿主写模板 id）；不给时按页面地址区分。设置里开着自动保存时，未保存的修改停手约一秒存成这台浏览器里的草稿，保存（markSaved）后删掉；下次装进同一个键的模板、和草稿不一样时问恢复还是丢弃。同名 attribute draft-key。
autoTourauto-tourboolean | undefined第一次在设计态显示出来（画布有了尺寸）后自动开始新手引导，缺省开；设置里记过 help.tourDone（走完、跳过或关上过一次）时不再自动开始。写 false 关掉，start-tour 命令、帮助页的「开始引导」与 startTour() 照样能开始。同名 attribute auto-tour，写 "false" 是关。

存取器 ​

属性读写类型说明
xhConfig只读XhConfig设计器这棵子树的配置：设置里选了语言时是这一语言的 UI、designer-shell 与打印语言包，跟随页面时是空对象。设计器自己、里面的元素与它弹出的浮层都按它取 locale 与文案，页面别处不受影响。
schema可读写PrintDocument打印模板。赋值即装载：清空历史与选择，按实际大小放到视口左上（赋回当前这一份不重新装载）；读取时得到当前模板。
activePageId可读写string当前页面模板的标识；赋值切换页面模板。
canUndo只读boolean是否有可以撤销的修改。
canRedo只读boolean是否有可以重做的修改。
dirty只读boolean有未保存的修改。
extensions可读写readonly PrintDesignerExtension[] | undefined扩展：元素种类、编辑方式、规则、属性编辑器、命令与面板都从这里来，设计器自带的扩展与内置元素自动排在最前。赋值时当场合并查重，冲突抛 DesignerExtensionError、什么都不变；各扩展的 setup 在元素连上文档时调用、断开时清理。同一个扩展对象换了引用当作卸下再装上，宿主要保持引用稳定。

方法 ​

方法说明
execute(operations: readonly PrintOperation[], options?: ExecuteOptions): PrintDocument执行一组操作并记为一步撤销；返回新的模板。
undo(): boolean撤销一步；没有可撤销的修改时返回 false。
redo(): boolean重做一步；没有可重做的修改时返回 false。
markSaved(): void把当前状态记为已保存。
addElement(type: string, at?: Point, options?: { readonly region?: ElementRegion }): PrintElement新建元素并选中：at 是元素中心的纸张坐标（mm），缺省放在视口中央；位置吸附网格，region 缺省按落点所在区决定。
select(selection: Partial<PrintSelection>): void替换当前选择；不在当前页面模板正文与当前显示的页眉页脚变体里的元素会被忽略。
getSelection(): PrintSelection当前选择。
deleteSelection(): boolean删除选中的元素；只读或没有选中时返回 false。
copy(): PrintClipboard | undefined复制选中的元素；没有选中时返回 undefined。
cut(): PrintClipboard | undefined复制并删除选中的元素；只读或没有选中时返回 undefined。
paste(clipboard?: PrintClipboard): PrintSelection粘贴到当前页面模板并选中粘贴出的元素；缺省用最近一次复制的内容，连续粘贴依次错开。只读时不粘贴。
duplicate(): PrintSelection复制选中的元素并立即粘贴，不改动剪贴板；只读时什么都不做。
align(mode: AlignMode): void对齐选中的元素；少于两个或只读时什么都不做。
distribute(axis: DistributeAxis): void等距分布选中的元素；少于三个或只读时什么都不做。
reorder(target: ReorderTarget): void调整选中元素的层级。
openSettings(section?: string): void打开设置对话框，给了分区 id 就显示那一页：基础是 general，设计器自己的「画布」是 print。
openJsonEditor(): void打开编辑整份模板 JSON 的对话框：写出当前模板，边改边按打印的校验报问题；没有错误时「应用」整份换上，记一步撤销。只读时只能看、不能应用。
startTour(): boolean从头开始新手引导：通用步骤加打印与扩展的步骤，同一页里别的引导开着时先收起它；预览态或没有能走的步骤时返回 false。
openFieldImport(source?: string): void打开导入字段对话框，给了页 id 就显示那一页：内置的是 sample 与 json-schema，扩展的字段来源用它的 id。
validate(): ValidationIssue[]按当前登记表与表达式引擎校验模板。
getViewport(): Viewport视口：屏幕坐标 = 纸张坐标（mm）× zoom × 96 / 25.4 + (x, y)；zoom 为 1 时是实际尺寸。
setViewport(viewport: Viewport): void设置视口；此后尺寸变化不再自动适配。
zoomToFit(): void让整张纸连同左侧的页眉页脚标签落在视口中央，让开浮在画布一侧的翻页条（让出的宽度与四周留白取较大的那个），不放大到实际尺寸以上；此后尺寸变化时重新适配，直到设置视口或在画布上操作。
zoomIn(): void以视口中心放大一档。
zoomOut(): void以视口中心缩小一档。
zoomToActual(): void实际尺寸，纸张居中。
scrollToElement(id: string): void切到元素所在的页面模板与带区变体，并把元素居中。
revealElement(id: string): void切到元素所在的页面模板与带区变体；元素没整个落在视口内时把它居中。
clientToWorld(clientX: number, clientY: number): Point浏览器视口坐标换成纸张坐标（mm）。
print(options?: PrintPreviewPrintOptions): Promise<PrintOutcome>按当前模板与 data 打印，等同 <xh-print-preview> 的 print。

事件 ​

事件都是冒泡的 CustomEvent。

事件detail说明
schema-change{ schema: PrintDocument, operations: readonly PrintOperation[], kind: PrintSchemaChangeKind }模板变了：schema 为变化后的模板，operations 为实际应用的操作；一次拖动、一次属性编辑等事务提交时合成一次，宿主装载新模板时 kind 为 load、operations 为空。
selection-changePrintSelection选择变了，detail 为当前选择。
dirty-change{ dirty: boolean }是否有未保存的修改变了。
issues-change{ issues: readonly ValidationIssue[] }模板改动或登记表、表达式引擎换了之后重新校验，detail 为全部校验问题。
viewport-change{ viewport: Viewport }视口变了，取值同 getViewport()。
saveRecord<string, never>执行了保存命令 save：选了菜单栏的「文件 → 保存」，或设计态下焦点在设计器里（输入框与面板之外）时按了 Ctrl / ⌘ + S；设计器不保存，宿主保存后调用 markSaved()。
element-dblclick{ id: string }双击元素；双击表格时同时进入表格编辑态。
element-contextmenu{ id: string, x: number, y: number }在元素上打开右键菜单，未选中的元素先被选中；可取消，取消后不弹设计器自带的菜单。
blank-contextmenu{ x: number, y: number }在画布空白处打开右键菜单；可取消，取消后不弹设计器自带的菜单。
table-contextmenu{ id: string, part: PrintTablePart, x: number, y: number }在表格编辑态里打开右键菜单，右键处的表格部位先被选中；可取消，取消后不弹设计器自带的菜单。
import-error{ importer: string, source: DesignerImportSource, error: unknown }导入器没能导入粘贴或拖放进来的内容：它抛了错，或给出的元素没有通过校验；importer 是导入器的 id。
page-change{ pageId: string }当前页面模板变了。
mode-change{ mode: PrintDesignerMode }在设计态与预览态之间切换了。
settings-change{ key: string, value: JsonValue | undefined, settings: DesignerSettings }改了一条设置（设置对话框里，或工具栏上的网格、吸附开关）：设计器已换成新的 settings 并生效；value 为 undefined 表示删掉这个键、回到缺省值。宿主存起来，下次赋回 settings。
settings-storage-errorVisualEnvironmentStorageError读写 settingsStorageKey 指的本机存储失败（内容不是对象、无痕窗口、配额满）；设置留在内存里。
fields-change{ fields: readonly DataField[] }在导入字段对话框里导入了字段：设计器已换成新的 fields。宿主存起来，下次赋回 fields。
sample-data-change{ sampleData: JsonValue }导入字段时勾了「同时作为示例数据」：设计器已换成新的 sampleData。宿主存起来，下次赋回 sampleData。

类型 ​

PrintDesignerMode ​

设计态或预览态。取值：design、preview。

PrintSchemaChangeKind ​

schema-change 的种类：执行操作、撤销、重做，或宿主装载了新模板。取值：execute、undo、redo、load。

PrintSelection ​

选择：都在当前页面模板的正文与当前显示的页眉页脚变体里；tablePart 只在表格编辑态下出现。

属性类型说明
elementsreadonly string[]
tablePart?PrintTablePart

PrintTablePart ​

表格编辑态下选中的部位。

| { readonly kind: 'column', readonly elementId: string, readonly columnId: string } | { readonly kind: 'header' | 'body', readonly elementId: string } | { readonly kind: 'footerRow', readonly elementId: string, readonly rowId: string } | { readonly kind: 'footerCell', readonly elementId: string, readonly rowId: string, readonly columnId: string }

PrintClipboard ​

剪贴板内容：被复制的元素与它们所在的区域。

编辑模型 ​

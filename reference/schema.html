模板类型 ​

模板文档 PrintDocument 的全部类型，按 @xihan-print/core 的源码列出。当前 schema 版本 PRINT_SCHEMA_VERSION 为 1。

长度单位为 mm，字号与字间距单位为 pt，角度单位为度；颜色写作 #RGB、#RGBA、#RRGGBB、#RRGGBBAA 或 transparent。

文档与页面 ​

PrintSchemaVersion ​

模板 schema 版本号类型。

类型：typeof PRINT_SCHEMA_VERSION

PaperSpec ​

纸张。宽高为纵向尺寸，单位 mm；横向时宽高互换。

字段类型必填说明
presetPaperPresetName可省来源预设，自定义纸张不填。
widthnumber是
heightnumber是

PageBand ​

页眉或页脚的一个带区。

字段类型必填说明
heightnumber是带区高度，单位 mm。
elementsPrintElement[]是带区内的元素，坐标相对纸张左上角。

PageBandSet ​

页眉或页脚：default 为常规带区，其余为按输出页命中的变体。命中顺序为首页、末页、奇偶页，都未命中时使用 default。

字段类型必填说明
defaultPageBand是
firstPageBand可省
lastPageBand可省
oddPageBand可省
evenPageBand可省
singleSheetSingleSheetPreference是输出页既是首页又是末页且两种变体都存在时采用哪一个。

PageNumbering ​

页码编号规则。

字段类型必填说明
continuousboolean是是否接续上一页面模板的页码；为 false 或没有上一页面模板时从 start 开始。
startnumber是起始页码。

Watermark ​

平铺文字水印。

字段类型必填说明
textstring是水印文字，支持 {{path}} 占位。
fontFamilystring可省
fontSizenumber是字号，单位 pt。
colorColor是
opacitynumber是不透明度，0 到 1。
rotationnumber是逆时针旋转角度。
gapXnumber是相邻水印的水平间距，单位 mm。
gapYnumber是相邻水印的垂直间距，单位 mm。

PageGuides ​

参考线：设计时对位用，不参与分页也不打印；坐标相对纸张左上角（按页面方向换算后的纸张），单位 mm。

字段类型必填说明
xnumber[]是竖线的横坐标。
ynumber[]是横线的纵坐标。

PrintPage ​

页面模板：一份页面模板按数据量排出一张或多张输出页。页眉位于上边距之下，页脚位于下边距之上，两者之间为正文区。

字段类型必填说明
idstring是页面标识，在整份文档内唯一。
namestring可省
paperPaperSpec是
orientationPageOrientation是
marginsEdges是页边距，单位 mm。
headerPageBandSet是
footerPageBandSet是
elementsPrintElement[]是正文元素，坐标相对纸张左上角。
numberingPageNumbering是
watermarkWatermark可省
guidesPageGuides可省
metaJsonObject可省
extensionsJsonObject可省扩展自己的数据，键是扩展 id。

RichTextContent ​

富文本的内容来源：模板里写死的文档，或从数据字段读取。字段值是 HTML 串时（source 为 html）按白名单换成文档，字段值已是富文本文档对象时 source 为 document。文档是 @xihan-ui/core/rich-text 的 RichTextDocument，其中行内字段的 format 按值格式解释。

类型：| { kind: 'static', document: RichTextDocument } | { kind: 'field', field: string, source: RichTextSource }

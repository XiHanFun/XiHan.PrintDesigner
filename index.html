曦寒打印设计器框架无关的打印模板设计器

原生 Web Components · 模板即 JSON · 按数据分页 · 浏览器打印与静默直打

快速开始
介绍
  • 🧩

    框架无关

    以原生 Web Components 交付，Vue、React、Angular 或不用框架的页面都能直接使用；同一页面放多个实例互不影响。

    了解设计原则

  • 📄

    模板即数据

    模板是纯 JSON，不含也不执行任何代码；需要计算的地方用受限表达式，导入模板不会带来脚本注入。

    了解模板结构

  • 📑

    按数据分页

    表格随数据续排到后续页，可重复表头、本页小计与合计、补空行；长文本与富文本按整行切到后续页；页眉页脚分首页、末页、奇偶页，页码分段编号。

    了解分页规则

  • 🔗

    数据绑定与格式化

    文本可绑定字段、写占位模板或受限表达式；数字、百分比、日期、人民币大写与值映射，按十进制精确舍入。

    了解数据绑定

  • 🎨

    可视化设计器

    物料面板、标尺与参考线、吸附对齐、属性面板、问题列表、表格编辑与撤销重做；模板的保存与权限交给宿主。

    了解设计器

  • 🖨️

    本地打印客户端

    Windows 托盘程序，只监听本机、按网站授权；静默打印到指定打印机，原始指令直送，导出 PDF。

    了解打印客户端
